TUI — SIX TERMINAL APPS ON ONE CHARACTER GRID →

A system monitor with per-core bars and a killable process table, a three-column mail reader that replies and deletes, a file manager with a git index next to it, a music player whose spectrum reads its own WebAudio graph, a services-and-logs board that is genuinely live, and a modal editor with modes, operators, undo and an ex line. Six jobs, six layouts, six palettes and six box-drawing dialects on one static kit: every key is a key, every key is also a button you can tap, and a headless pass drives the keyboard and reads the state back at desktop and phone widths.

Each page is checked in headless Chromium (software renderer on this box, so the FPS numbers are a floor): console, page and network errors, an interaction driven from the harness into the page's own window.experiment hook, and FPS sampled before and after it. The checkers are games/tools/verify.mjs, experiments/tools/check.mjs, design/tools/shoot.mjs, eyecandy/tools/check.mjs and and tui/tools/check.mjs (screenshots plus a console, contrast, landmark, control-name and overflow audit; the two things it used to be blind to are written down in design/README.md). The TUI checker is a different shape of check: keys, taps and poses driven into the page, its own state() read back to prove they landed, and every glyph it draws measured against the loaded face, because a font that falls back silently breaks a character grid.

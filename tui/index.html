strata-test / tui

tui·six

Six terminal apps drawn on the Strata FP4 character grid, each a plain static page — no build, no server, no canvas. Every one answers its keys, and every key is a button you can tap on a phone. Different jobs, different layouts, different palettes and box-drawing dialects: the point is to see how much range one grid has.

1 pulsesystem monitor · btop

Per-core load in eighth-block bars, memory, a network sparkline and a process table you can sort, filter and kill. Three palettes, live for two seconds a tick.

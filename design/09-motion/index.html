Halyard · motion study · twelve interactions, one system

Motion is an answer to a question about space.

A sheet that slides in from the bottom says this came from the tab bar. A row that grows says something was added here. A fade with no movement says this changed and nothing moved. Where the frame comes from is the sentence. Everything on this page is a real animation that the page can scrub: the strips show the frames a person sees, not paintings of them.

Synthetic. Fictional product, invented data, no network calls, no framework, no build step.

Scrubbed, not staged. Every frame in a strip is a paused Web Animation with its currentTime set to a millisecond. Play runs the same animation.

01 The system

Four durations, four curves, one rule: a thing that enters decelerates, a thing that leaves accelerates, and nothing animates a property that moves other things.

Curves

    Two properties, at most

    Only transform and opacity are animated. They are composited; width, top, box-shadow and font-size make the browser lay out and paint the page 60 times a second. Height changes are hidden behind a grid row or a clip, so the layout work happens once.

    Enter decelerates, leaves accelerates

    A thing arriving has to be catchable, so it starts fast and settles: cubic-bezier(0.16, 1, 0.3, 1). A thing leaving is already gone from the person's attention, so it speeds up: cubic-bezier(0.4, 0, 1, 1) at a shorter duration. Nothing bounces for cheer.

    Movement is a pointer, not a decoration

    A transition must answer “where did that come from, and where did it go?”. A shared element, a parent-child link, a row that grows: the movement names the relationship. If a strip of frames would not teach a person anything, the animation is cut.

    Nothing waits for the animation

    Input is accepted during a transition, and the state is final the moment the intent is. The toast is dismissible while it flies in; the sheet is scrollable before it settles; the row is added to the data before it grows.

    Announce the fact, not the movement

    Every animated change has a text equivalent that is not animation-dependent: the toast is a live region, the sheet is a dialog, the row is in the list, the count is in the button's label. A person on a screen reader gets the same news.

    Reduced motion is a redesign, not an off switch

    Durations go to 0 ms. Where movement carried meaning, it is replaced with a static cue: a spatial relationship becomes a heading and a scrim; a growing row becomes a row at the top of a list labelled “added”; a spinner becomes the word “Saving”.

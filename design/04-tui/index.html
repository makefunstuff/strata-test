logtrail — a log tail that fits a terminal

Four hundred and twenty lines from a fictional API gateway fleet, drawn in a box-padded grid with 24-bit colour: the tail on the left, the selected line decomposed on the right, a 60-bucket volume histogram along the bottom. One TypeScript file, no dependencies, no curses, no React. Every frame below is the bytes the program prints, rendered by a small ANSI reader — not a redraw of the design.

How a frame is made

Every widget writes a line of exactly the pane's visible width, then the panes are concatenated and clipped to the terminal width. Colour codes do not count towards width, so vis() strips them before measuring — that is the whole trick that keeps the right-hand pane's border in the same column on every row.

// the row body, then the exact clip that keeps the grid true
const row =
  fg(pal.line) + "│" + (on ? bg(pal.sel) : "") + " " +
  (on ? fg(pal.selInk) + BOLD : fg(pal.faint)) + r.t.slice(0, 8) + " " +
  s(on ? pal.selInk : pal.dim, pad(r.svc, w.svc)) + " " +
  (compact
    ? s(on ? pal.selInk : pal.ink, clip(r.msg, listW - 39))
    : s(on ? pal.selInk : pal.ink, pad(r.ep, w.ep)) + " " +
      (r.lat > 900 ? fg(pal.red) : r.lat > 300 ? fg(pal.gold) : fg(pal.dim)) +
      pad(String(r.lat), w.ms, true) + "  " +
      s(on ? pal.selInk : pal.dim, clip(r.msg, listW - 74)));
P.push(clip(row, listW - 1) + fg(pal.line) + "│");   // the shared rule

At 80 columns the app drops the endpoint and latency columns, shortens the tab labels and removes the per-level counts. The detail pane only appears at 128 columns and above. Nothing scrolls sideways.

What is real

  • The captures are the program's output. tools/capture.sh runs the app at a fixed size, writes the ANSI bytes to capture/*.ansi, and capture.html renders them.
  • The filter is a query language, not a placeholder — lvl=, svc=, ep=, code= and free text, applied to the tail and the endpoint table together.
  • Colour is the threshold, not a legend. p95 over 900 ms is red, over 300 ms amber; the same thresholds colour the latency column and the histogram buckets.
  • The data is invented and says so — a fictional gateway fleet, seeded so every capture is reproducible.

The palette, and what each colour is for

The program declares two palettes, one table each, and every colour in them has a job: the thresholds are colour (over 300 ms amber, over 900 ms red), the levels are colour (trace faint, debug blue, info teal), and the rules are structure. The ratio beside each swatch is computed in the page from the same hexes the program prints, on the ground each palette sits on — type is held to 4.5:1, rules and bars to 3:1, and the need is printed next to the number so a pass is not a colour-coded claim. 04-tui/measure.mjs re-reads the table from src/logtrail.ts and fails if a swatch drifts, a ratio is misprinted, a colour has no job, or a colour falls under its bar. Two colours that were in the table with no job anywhere in the program (a violet, a panel fill) were deleted rather than displayed.
